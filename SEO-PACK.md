# MathStudy.in — Buy-Intent SEO Pack (Yoast / WooCommerce)

Goal: rank for **commercial "buy / PDF / with-solutions"** searches the free giants ignore,
and win the **price + ⭐ rich snippet** so more clicks convert to sales.

How to use: do **Part A once** (10 min, fixes all 40 products at once), then work down
**Part C** product-by-product in WooCommerce → edit product → Yoast snippet editor.

---

## PART A — Global fixes (do these FIRST, once)

1. **Kill the bloated title suffix** (biggest quick win).
   Your titles end with `… Best E-books, Mathematics, Sample Papers - CBSE, ISC, ICSE, JEE, BITSAT & SAT`.
   - WP Admin → **Settings → General → Tagline**: change to `Math e-books & worksheets PDF` (short).
   - Yoast → **Search Appearance → Content Types → Products → SEO title** template: set to
     `%%title%% %%sep%% %%sitename%%`  (so default = "Product Name | MathStudy.in").
   - Yoast → **Search Appearance → Content Types → Products → Meta description**: leave blank (we set per-product).

2. **Turn on Product rich results (price in Google).**
   Install **Yoast WooCommerce SEO** (or ensure Yoast Schema → Product is active). With WooCommerce,
   Yoast auto-outputs `schema.org/Product` with **price, currency (INR), availability** — no manual JSON needed.
   Confirm later at Google **Rich Results Test**.

3. **Turn on reviews → ⭐ stars.**
   WooCommerce → Settings → Products → **Enable reviews** + **star ratings**. Seed 3–5 *honest* reviews per
   top product (ask past buyers by email). Ratings appear in Google via Product schema.

4. **FAQ rich result.** Use the **Yoast FAQ block** inside each product's long description and paste the
   Q&As from Part C. Yoast generates valid `FAQPage` schema automatically.

5. **Breadcrumbs on:** Yoast → Search Appearance → Breadcrumbs → Enable (helps SERP + internal links).

6. **Sitemap:** Yoast XML sitemap is on by default → submit `mathstudy.in/sitemap_index.xml` in
   **Google Search Console** (free). Also add the site to **Bing Webmaster Tools**.

---

## PART B — The strategy (rules for every title/meta)

- **Lead with the commercial keyword**, include **"PDF"** + the **class/exam**.
- Put a **buy/benefit word**: *with solutions, with answers, printable, instant download, solved*.
- Title ≤ **60 chars**, meta ≤ **155 chars**, each **unique** (never reuse the same sentence).
- We deliberately **do NOT chase** "class 10 maths sample paper" (free-intent, Vedantu-owned).
  We chase the **long-tail buyer**: e.g. *"class 12 probability case study questions pdf"*.
- Focus keyword should appear in: SEO title, meta, H1 (product name), first line of description, and 1 FAQ.

## PART E — How to apply in Yoast (per product, ~1 min each)

1. WP Admin → **Products** → open a product → scroll to the **Yoast SEO** box.
2. Click **Edit snippet** → paste the **SEO title** and **Meta description** from Part C.
3. Set the **Focus keyphrase** field = the Focus keyword.
4. In the product **long description**, add a **Yoast FAQ block** and paste the 3 Q&As.
5. Make sure the focus keyword appears in the **first sentence** of the description (rewrite the opening line if needed).
6. **Update**. Repeat. Start with the 8 JEE/Class-12 products (highest buy-intent), then the rest.
